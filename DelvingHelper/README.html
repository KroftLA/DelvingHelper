LOTRO Plugin • v1.5.16

DelvingHelper

Ваш внутриигровой помощник по дельвингам, ротациям миссий и еженедельным наградам в LOTRO

🎯 О плагине

DelvingHelper — это специализированный внутриигровой аддон для The Lord of the Rings Online, созданный для максимально быстрого и комфортного фарма свитков дельвингов (Delving Writs) и закрытия еженедельных миссий.

Плагин избавляет от необходимости сверяться со сторонними таблицами в браузере: он прямо в игре показывает только активные сегодня быстрые миссии, текущее злодеяние дня (Malice) и автоматически считает квесты через игровой чат.

📊 Автоматические счётчики квестов

1. High Tier Delvings (0/10)

Считает дельвинги строго 6-го тира и выше. Не накручивается от обычных миссий 1 тира!

2. On A Mission (Weekly) (0/15)

Еженедельный квест на любые 15 миссий. Автоматически пополняется при завершении любой миссии.

3. On A Continuing Mission (0/45)

Большой еженедельный квест на 45 миссий. Автоматически отслеживается из системных сообщений игры.

Правила еженедельного сброса LOTRO
В четверг в 11:00 МСК завершённые квесты сбрасываются в 0, а незаконченный прогресс (например, 28/45) плагин бережно сохраняет на следующую неделю, в точности как игра!

🌟 Ключевые возможности

  • Ежедневная ротация: Плагин знает расписание всех 7 дней недели и показывает только те миссии, которые доступны прямо сейчас.
  • Спидран-маршруты (Burglar Route & Standard): Отображаются самые короткие и быстрые миссии без долгих перебежек и сложных боссов.
  • Фильтры хабов: Удобные вкладки: Кардолан (Андрат), Сванфлит (Херне), Военная комната Аннак-Хурфу, Гундабад или все вместе.
  • Злодеяния (Delving Malice): Описание активной опасности дня, рекомендуемые зелья (Wound, Poison, Disease, Fear) и тактика боя.
  • Travel Tray: Встроенная складная панель для быстроходов и возвратов в хабы миссий.
  • Быстрый поиск и фильтр: Мгновенный поиск по названию и кнопка Incomplete (показывает только те миссии, что ещё не пройдены сегодня).
  • Релоадер в 1 клик: Правый клик по значку плагина $\to$ Reload Plugin для обновления на лету без зависаний.

📦 Установка

  1. Распакуйте скачанный архив DelvingHelper_v1.5.16.zip в папку плагинов игры:
    Документы\The Lord of the Rings Online\Plugins\
  2. В игре включите плагин через меню System $\to$ Plugin Manager или командой в чате:
    /plugins load DelvingHelper

💬 Команды в чате

/dh или /delving — открыть / закрыть главное окно
/dh reload — мгновенно перезагрузить плагин
/dh count 0 0 0 — сбросить или выставить вручную все 3 счётчика
/dh count45 <число> — вручную задать счётчик 45 миссий
/dh count15 <число> — вручную задать счётчик 15 миссий
/dh count <число> — вручную задать счётчик дельвингов
/dh center — вернуть окно в центр экрана (если потерялось)

🎯 About DelvingHelper

DelvingHelper is an essential, high-performance in-game companion for The Lord of the Rings Online designed for rapid Delving Writs farming and weekly mission wrapper completions.

No need to alt-tab to external wiki spreadsheets: DelvingHelper automatically tracks daily mission schedules, highlights fast speedrun routes, displays current Delving Malice hazards with potion tips, and logs quest progress directly from the game chat.

📊 Automated Quest Tracking

1. High Tier Delvings (0/10)

Strictly tracks Delvings at Tier 6 or higher. Never advances falsely on Tier 1 runs!

2. On A Mission (Weekly) (0/15)

Tracks your weekly 15-mission wrapper across any difficulty. Synchronized from game chat.

3. On A Continuing Mission (0/45)

Tracks the 45-mission weekly wrapper quest automatically with independent steppers.

LOTRO Weekly Reset Compliance
On Thursday at 03:00 Server Time (EST), completed quests reset to 0, while incomplete progress (e.g. 28/45) is faithfully preserved into the new week.

🌟 Core Features

  • Automated Daily Rotations: Detects the active server day and displays only the missions officially available today.
  • Curated Speedrun Routes: Pre-filtered lists for the shortest, safest, and fastest instances with minimal mob density.
  • Hub Filters: Instant tabs for Cardolan (Andrath), Swanfleet (Herne), War Room (Annak-khurfu), Gundabad, or All Hubs.
  • Delving Malice Guide: Real-time breakdown of today's hazard, recommended curative potions (Wound, Poison, Disease, Fear), and combat tactics.
  • Collapsible Travel Tray: Built-in shortcut tray for return maps and fast-travel skills directly inside the plugin window.
  • Live Search & Incomplete Filter: Filter cards by keywords or click Incomplete to hide missions you have already completed today.
  • 1-Click Instant Reloader: Right-click the jewel icon $\to$ Reload Plugin to update smoothly without freezing or console commands.

📦 Installation

  1. Extract the downloaded DelvingHelper_v1.5.16.zip archive into your LOTRO plugins folder:
    Documents\The Lord of the Rings Online\Plugins\
  2. In-game, load the plugin via the Plugin Manager or by typing:
    /plugins load DelvingHelper

💬 Chat Commands

/dh or /delving — Toggle main window
/dh reload — Instantly reload the plugin on the fly
/dh count 0 0 0 — Set or reset all 3 counters
/dh count45 <n> — Set 45-mission weekly counter
/dh count15 <n> — Set 15-mission weekly counter
/dh count <n> — Set High Tier Delvings counter
/dh center — Re-center windows if moved off-screen
